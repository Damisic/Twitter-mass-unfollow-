A lightweight Chrome Extension (Manifest V3) to automate the management of your X (Twitter) following list. Identify and mass-unfollow accounts that do not follow you back with built-in safety delays to protect your account.
Built by @0xDamisi.

Features
Custom Unfollow Limits: Input the exact number of accounts you want to unfollow.
Cross-Check Logic: Automatically detects the "Follows you" badge and skips mutual followers.
Auto-Scrolling: Automatically scrolls through your following list to load more users.
Safety Delays: Implements randomized human-like delays (5–12 seconds) between actions to mimic real user behavior and avoid X's automation detection.
Clean UI: Simple, Twitter-themed popup interface.

🛠️ Installation (Developer Mode)
Since this extension is built for personal use and developer testing:
Download the Code:
Clone this repository: git clone https://github.com/YOUR_USERNAME/twitter-mass-unfollow.git
Or download the .zip file and extract it.
Open Chrome Extensions:
Navigate to chrome://extensions/ in your Google Chrome browser.
Enable Developer Mode:
Toggle the Developer mode switch in the top-right corner.
Load the Extension:
Click the Load unpacked button.
Select the folder containing the extension files (manifest.json, content.js, etc.).

How to Use
Open your browser and navigate to your X profile's Following page:
https://x.com/[YourUsername]/following
Click the X Mass Unfollower icon in your extension toolbar.
Enter the number of non-followers you wish to remove.
Click Start Cross-Check.
Keep the tab open. You can track the progress by right-clicking the page, selecting Inspect, and clicking the Console tab.


⚠️ Safety & Limits
Twitter/X has strict policies regarding automation. To keep your account safe:
Daily Limits: It is recommended to unfollow no more than 100–200 accounts per day.
The Delay: This script uses a mandatory 5-10 second delay. Do not modify this to be faster, as rapid clicking will result in a temporary account lock or suspension.
Use at your own risk: This tool is for educational purposes. The author is not responsible for any actions taken by X against your account.
